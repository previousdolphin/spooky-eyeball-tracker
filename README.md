# Spooky Eyeball Tracker

Spooky Eyeball Tracker is a promotional site for an interactive WebGL art installation: a floating, glossy, bloodshot 3D eyeball that uses the visitor's webcam to estimate who is standing closest to the lens and turns to stare at them. The page explains the concept, the technical process behind the tracking, a materials/engineering spec sheet, a field-notes gallery, and an inquiry form for commissioning a physical installation.
